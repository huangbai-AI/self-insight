# 自我洞察

读取经本人授权的本地消息记录，分析行为模式、优势与盲点，生成有依据的自我洞察报告与人生、事业行动规划。

## 完整内容

- `SKILL.md`：使用范围、完整工作流程、判断边界与交付检查。
- `references/method.md`：覆盖与取样、证据判断、规划和复核方法。
- `scripts/prepare_evidence.py`：本地统计与上下文候选整理脚本。
- `agents/openai.yaml`：技能展示和调用配置。

这是一份完整技能，包含操作方法和可运行脚本。仓库不含任何真实聊天、个人报告或授权信息。

## 安装与使用

在终端执行：

```bash
git clone https://github.com/huangbai-AI/self-insight.git ~/.codex/skills/self-insight
```

若该目录已存在，请先检查现有内容，避免覆盖。重新打开会话后，可以直接说：

> 使用 $self-insight 分析我授权的最近一个月消息记录，帮我理解自己的行为模式、优势与盲点。我希望找到长期方向，做出自己的事业。

提供本人授权的本地记录位置与需要分析的时间范围。已有导出文件优先使用；需要读取更新记录时，按技能中本地读取工具的授权规则操作。

## 本地整理脚本

需要 Python 3，仅使用标准库，无需额外安装程序包。脚本接收每行一条消息的 JSONL 文件；消息需包含会话标识 `talker`、本人标识 `from_me`、秒级时间 `create_time`（或带时区的 `time`）、类型 `kind_name` 和正文 `text`（或 `content`）。

`from_me` 支持布尔值、0/1，以及对应的字符串；无法识别时记为未知，不计入本人消息。正文候选支持 `text` 与 `quote`；附件只保留未读取的占位信息。

```bash
python3 ~/.codex/skills/self-insight/scripts/prepare_evidence.py \
  --input /absolute/path/messages.jsonl \
  --output /absolute/path/local-work/evidence \
  --since '2026-01-01T00:00:00+08:00' \
  --until '2026-02-01T00:00:00+08:00'
```

示例日期请换成实际窗口：开始包含，截止不包含。输出目录必须不存在。结果为 `统计.json` 和 `上下文候选.json`，用于回看原文和整理证据，不是自动生成的人格结论。

## 使用边界

记录与候选包留在本地。会话代号及部分敏感字段过滤不能保证正文完全匿名，因此不要把生成的证据包上传到公开仓库。

分析区分本人表达、转发、他人发言与附件；判断附证据、反例和其他解释。消息量不等于工时或压力，夜间消息不等于失眠。报告不提供疾病诊断或必然成功的预测；只有用户明确要求时，才给出低可信的娱乐性人格类型猜测。

行动规划围绕用户自己的目标、现实资源与约束展开，并设置七天、三十天、九十天的观察与调整节点。
