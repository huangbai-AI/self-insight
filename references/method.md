# 分析方法

## 覆盖与取样

记录来源、账号、时间与时区、消息数、本人消息数、本人参与会话数、类型与附件覆盖。区分全量机器筛查、人工抽样与上下文阅读；不要为增加样本量扩大用户授权范围。

三层取证：自然交流中的本人表达；不同日期和情境重复发生的选择；他人具体反馈与可确认结果。自存计划不是已执行制度，宣传稿不是自然表达，他人赞美可能只是礼貌。特别检查主语，避免把对方的处境写成用户的情况。

优先筛查本人表达，再读相关双方上下文。补充不同周、不同联系人的非关键词样本，避免只挑命中自己结论的例子。最活跃联系人不能代替全部生活；没有随机取样就不声称随机。相同事件被多次转发仍是一个事件。

## 判断表

每项重要判断在工作笔记中记录：

| 字段 | 要求 |
|---|---|
| 判断 | 具体、可以被否定的解释 |
| 证据 | 日期、会话代号、发言人、源行号、必要短句 |
| 力度 | 明确自述／多场景支持的推测／弱线索 |
| 反例 | 真实相反证据；没找到就说明没找到 |
| 其他解释 | 工作要求、临时事件、玩笑、生成稿等 |
| 影响 | 与用户当前目标的联系 |
| 验证 | 什么新事实会改变判断 |

稳定倾向通常需要跨日期和场景支持，单个事件只讨论该事件。自述与行为有差异时先检查约束，不立即指责缺乏自律。

可观察动力、取舍、学习创造、执行、合作边界、责任、关系、生活节奏、资源和限制。维度只是视角；没有足够证据就不写。未完整读取语音时，对关系判断尤其保守。

## 规划

寻找“表达目标—时间与承诺—可用资源”的关系，也可能发现它们一致，此时强化有效做法，不制造矛盾。

主线需说明为什么适合当前证据，未知关键条件要有备选和转向条件。动作解释具体做什么、何时做、依赖什么、怎样检查、何时调整。七天处理一个可控问题，三十天取得观察，九十天评估路线；试行数量不是科学最优值。

区分收入、利润、现金到账与支出。未知时建议盘点，不能替用户确定能承担的金额。考虑已有承诺，避免冲动辞职、切断收入、替关系双方决定去留。

只选一个改变时，选择用户可控制、对目标影响大且较易验证的行为，避免“更自律”“寻找热爱”。

## 表达与复核

区分“你说过”“这些行为支持一种解释”“目前不能确认”。不假装洞悉潜意识，不讨好，不表演残酷真相，不给永久标签或必然成功的预测。

引用删去账号、验证码、地址、身份和联系方式；必要时只用关系角色。技能包和示例只能含虚构数据，不含安装者的聊天、姓名、私人路径或商业资料。

末尾保留一到三个真正影响下一步的未知问题，不以庞大问卷阻止已有分析。
